## How promo codes and cashback work together

A promo code and cashback solve different parts of the purchase.

A code may reduce the order total before payment. Cashback usually arrives later, after the retailer confirms that the transaction was eligible. For example, if a store accepts a 15% promo code and also offers cashback through ShopBack, the code may reduce the amount paid while cashback is calculated on the eligible purchase amount defined by the retailer.

That does not mean every code can be stacked. Retailers set their own rules, and ShopBack warns that a code not listed on the retailer’s ShopBack page may make the order ineligible for cashback. The same can happen if another coupon website, browser extension, or affiliate link overwrites the ShopBack tracking session.

Before entering a code, check these points:

- Is the code displayed on the ShopBack retailer page?
- Does the offer say that cashback remains eligible?
- Is the code limited to first-time customers?
- Does the cart meet the minimum spend?
- Are sale items, gift cards, subscriptions, or marketplace products excluded?
- Does the code apply only to selected brands?
- Is the retailer using a single-code limit at checkout?

If ShopBack lists a coupon directly on the retailer’s offer page, it is generally the better option to try first. Random codes from search results may still work, but they are more likely to be expired, restricted, or incompatible with cashback.

## Why a promo code may fail

A code can look current and still fail at checkout. Retailer systems usually check several conditions at once.

The most common reasons include:

### The code is for new customers only

Many welcome offers apply only to the first order, first account, or first purchase from a particular device. Creating multiple accounts to repeat a welcome discount can also violate the retailer’s terms.

### The order total is too low

A code such as “$20 off $100” will not apply to a $95 cart. Check whether the minimum is calculated before tax, shipping, discounts, or gift cards.

### The products are excluded

Electronics, luxury brands, subscriptions, clearance items, gift cards, and marketplace products are frequently excluded from general promotional codes. The exclusions may appear in small text below the offer.

### The code has expired

Some retailer pages leave old codes visible in search results even after the campaign ends. A code shown on an unrelated coupon site is not evidence that it remains active.

### The retailer allows only one promotion

A discount code may not combine with another code, automatic sale, loyalty reward, or free-shipping promotion. The checkout system may silently remove one benefit.

### The code conflicts with cashback

If the code was not approved for the ShopBack offer, the order may still be accepted by the retailer but fail to generate cashback. ShopBack specifically advises users to check whether an external code is allowed before completing the purchase.

## What happens after checkout?

ShopBack uses different cashback statuses to show where the transaction is in the verification process.

**Pending** generally means that the purchase was recorded but the retailer has not finished validating it. The amount is not yet guaranteed.

**Confirmed** means that the retailer has approved the transaction after accounting for returns, cancellations, refunds, and exclusions.

**Withdrawable** means the confirmed balance has reached the applicable threshold and can be sent through an available payout method.
